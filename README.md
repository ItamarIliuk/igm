# Industrial Gauge Monitor (IGM)

Public project page: https://itamariliuk.github.io/igm/

IGM reads the analog pressure gauges already installed in factories with a low-cost camera and NVIDIA Cosmos
running locally, and sends the pressure in bar and psi to SCADA and to the cloud. It is developed at LABRIOT
(Laboratório de Robótica e IoT), UTFPR Ponta Grossa (Brazil). LABRIOT is a member of the NVIDIA Inception program.

This repository holds only the static web page (`index.html` and `assets/`). The NVIDIA Inception Program badge is
used as provided by NVIDIA, unmodified.
